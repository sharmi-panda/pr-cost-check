# pr-cost-check (working name)

Estimate the cost of a data pipeline change before it is merged.

## The problem
Data teams usually learn that a pipeline change was expensive only when the monthly cloud bill arrives.

## What it will do
- Detect which job or cluster configuration changed in a pull request
- Post an estimated cost per run, with a range, as a comment
- Suggest a cheaper configuration

## Status
Early development. Not ready for use.
